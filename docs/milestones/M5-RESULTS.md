# M5 results — Remember, saved pages, snippets

Branch `claude/m5-remember-saved` (from `claude/m4-search-ui`). Verified locally: Node 22, Chromium 141 (full e2e) and Chrome for Testing 116 (new M4/M5 specs). GitHub CI not run on this branch.

## Implemented
- **Remember this page**: context menu "Remember this page" (page), keyboard command `remember-page` (suggested Ctrl+Shift+U / ⌘+Shift+U, provisional like all shortcut defaults), and message `sw/remember-tab` (trusted extension pages; same code path). Uses **activeTab + scripting** (granted by the menu click / command); no host permission, Deep Search untouched. Result feedback = tab-scoped action badge ✓ / ! (clears on navigation).
- **Save selection to memory**: context menu on a selection (text comes from the menu, so it also works where scripting is blocked) and the keyboard path (reads the selection from the tab). Stores the exact selected text, source URL, page title, time, and a **text-fragment** (`#:~:text=…`, `src/capture/text-fragment.ts`; short selections encoded whole, long ones as `start,end`). Snippet results in the search UI open at the passage (M4 `resultHref`).
- **Extractor v1** (`src/capture/extractor.ts`): one self-contained function injected with `executeScript({func})`: main/article/body content, skips scripts/styles/nav/header/footer/aside/forms/buttons/hidden subtrees, block-aware text, control-character stripping, repeated-token collapse, caps (50 KB text, 5 KB headings, 1 KB description), title/description/language; Deep-mode skip rules (password / payment-card fields, non-HTML, too little text) are built in for M6. Read-only on the DOM. **Deviation**: no `@mozilla/readability` (an injected function cannot import it, bundling it into a file-injection adds weight and a dependency); the custom extractor is tested in Node (linkedom) and in real Chromium.
- **Saved-state semantics** (engine, ADR-012 extended): `savePage` (idempotent; merges into an existing history record, keeping visit data), `unsavePage` (a page still in history keeps title/URL searchable but loses the saved text; a page that only existed because it was saved is deleted), `deleteSnippet`. Saved pages and snippets survive `deleteUrls`, `deleteAllExceptSaved`, retention and Chrome history deletion; snippets are independent saved items.
- **Restricted pages**: `chrome://`, extension pages, no URL → nothing stored, failure badge. An http(s) page that cannot be scripted (e.g. Web Store) is saved **title + URL only**.
- **Search UI**: row actions "Remove from saved" (saved pages) and "Delete snippet"; `is:saved` / `is:snippet` chips from M4; Saved/Snippet badges.
- **E2E build variant**: `npm run build:e2e` (`BR_E2E=1` → `.output-e2e`) adds `host_permissions: http://fixture.test/*` ONLY for tests (Playwright cannot trigger activeTab or accept the optional-host prompt); `fixture.test` is mapped to the local fixture server with `--host-resolver-rules`. The production manifest never contains it (unit test + built-manifest test). CI builds both for the e2e and Chrome 116 jobs.

## Engine API additions
`unsavePage({url})`, `deleteSnippet({id})` (contract, handler, store, tests). No schema change.

## Tests
Unit **273/273** (new: `tests/capture.test.ts` extractor + fragments, `tests/remember.test.ts` flows incl. idempotence, history-merge, restricted pages, title-only fallback, engine failure, selection, survival of history deletion/delete-all, unremember semantics). e2e **21/21** on Chromium 141 (new `e2e/remember.spec.ts`): visit page → consent/import → Remember (twice) → saved + found by body-only text (also Greek, accent-insensitive; footer/nav text not extracted) → save selection → snippet exact text + fragment → search UI shows Saved and Snippet → opening the snippet navigates with `:~:text=` → Chrome history deleted (single + delete-all) → saved page and snippet still searchable → "Remove from saved" / "Delete snippet" → restricted `chrome://version` fails gracefully. M4/M5 specs also pass on Chrome 116. typecheck/lint clean; `npm audit --omit=dev` 0; size JS 150.5 kB / all 558.3 kB gz (limits 160 / 620).

## Acceptance
Remember stores readable text and is findable by a body phrase — PASS (also Greek, article-like fixture; SPA/iframe/infinite-scroll fixtures not built). Saved survives history deletion/retention — PASS. Snippet opens with the passage highlighted on a stable fixture — navigation with the text fragment verified; the visual highlight itself is browser behaviour and is not asserted. Restricted pages degrade as specified — PASS. **Export/import UI**: engine round-trip is tested (M2) but there is no UI yet (needs the settings/options page, M6/M8) — NOT in M5.

## Risks / deferred
Toolbar-menu entry for Remember (action click opens search; M7/M8); text-fragment disambiguation with prefix/suffix context; default shortcut conflicts unverified on Windows/macOS; Remember cannot be started from a search result (needs the tab); extractor quality on SPAs/infinite scroll is best-effort; ZWNJ/ZWJ characters are replaced by spaces.
