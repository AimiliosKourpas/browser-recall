# ADR-010 Locked CSP and lint-enforced no-network — Accepted
CSP (`extension_pages`): `default-src 'none'; script-src 'self' 'wasm-unsafe-eval'; connect-src 'none'; img-src 'self' data:; style-src 'self'; base-uri 'none'; form-action 'none'; frame-src 'none'; object-src 'none'` — validated in Chromium 141 (M0 S5) and in M1 on 141 and Chrome 116 (extension loads with 0 manifest errors/warnings; page/worker/SW cannot reach a recording server). `frame-src 'none'` does not affect the future overlay (that iframe lives in the page, M0 S6).
Lint (ESLint flat config, `eslint.config.js`): bans `fetch`, `XMLHttpRequest`, `WebSocket`, `WebTransport`, `EventSource`, `importScripts`, `navigator.sendBeacon`, `window/self/globalThis/chrome/browser.fetch`, `eval`, `new Function`, string `setTimeout/setInterval`, `javascript:` URLs, `innerHTML`/`outerHTML`/`insertAdjacentHTML`/`document.write`/`dangerouslySetInnerHTML`, non-literal or URL `import()`, remote/computed `Worker` URLs, and `chrome`/`browser` inside the pure core (`src/engine`, pure `src/shared`). Applies to `src/`, `tests/`, `e2e/`. `tests/lint-rules.test.ts` proves every ban fires and that ordinary code is not flagged.
Test-only CSP probes use typed `page.evaluate(fn, arg)` (URLs passed as data, no code strings) and look up the banned APIs by name via `Reflect.get`, so source stays lint-clean without any disable.
Do not weaken the CSP or add a disable to make tooling easier; WASM needs only `'wasm-unsafe-eval'`.
